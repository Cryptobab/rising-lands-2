# Importers

These scripts read the original text-based game files and convert them into repo-owned data artifacts.

Current importer:

- `extract_classic_data.py`

Outputs:

- `game/data/classic/raw/`
- `game/data/classic/normalized/`

Current scope:

- `RISING.INI`
- `MONSTRE.INI`
- `TEXTES.TXT`
- `WORLD\MONDE*.TXT`

Current normalized export includes:

- units
- buildings
- spells
- tech tree
- strings
- missions
- misc game settings
